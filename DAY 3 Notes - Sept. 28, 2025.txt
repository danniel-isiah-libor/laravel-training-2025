* php artisan migrate - command for database migrations
* php artisan config:clear -clear/refresh config cache
* php artisan optimize - to clear/refresh all
* $table->timestamps(); - automatic created columns create_at, updated_at and automatic laravel updating those timestamps
* when naming tables, practice naming plural e.g. create_posts_table
* php artisan make:migration - create table
* do not migrate the database early, if columns are not yet finished setting up
* if accidentally made migration, just do migrate:rollback
* e.g. creating table:
$table->string('title', 255); //optional length value e.g. 255, 50, etc.
$table->text('content'); if no ->nullable; the field is required
* e.g. $table->foreignIdFor(User::class); //equivalent to user_id
* if you will add another column on a migrated table, make another artisan migration e.g. php artisan make:migration
named - e.g. add_new_column_to_posts_table
* e.g. $table->boolean('is_published')->default(false)->after('content'); //->after('content') -if you want to place the another column between other column, if no ->after() the new column will be placed at the end of the last column
* php artisan tinker //to generate or check e.g. fake()->firstName() -//it will generate fake/random name, e.g. fake()->lastName() -//it will generate fake/random last name, e.g. fake->randomNumber(2) -//generate two digit random number, e.g. fake->address() -//will generate random fake address, e.g. email() -//fake email -can generate true email so you may use safeEmail() -//will generate @example with .net, .org, .com, e.g. country() -//generate random country, etc.
* php artisan tinker
App\Models\Post::factory()->make() -//it will generate but will not save to database 
App\Models\Post::factory()->create() -//it will generate and save to database
App\Models\Post::factory()->count(10)->create() -//count() will generate and insert 10 fake records
* php artisan db:seed -//implement the code inside the run() in the DatabaseSeeder
* may create new seeder for the model - php artisan make:seeder
* creating seeders for all models is not necessary, it's case to case basis
* php artisan db:seed --class=PostSeeder -//run specific seeder
* don't leave empty method
