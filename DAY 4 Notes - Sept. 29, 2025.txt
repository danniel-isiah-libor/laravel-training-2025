* using Filament platform in Laravel
* install filament 
  composer require filament/filament:"~4.0" //install filament
  php artisan filament:install --panels //install portal e.g. /admin
  php artisan make:filament-user //create user for the portal
  In AdminPanelProvider.php - customize it according to your needs
  e.g. ->registration() //to add the user registration feature
  e.g. ->profile(isSimple: false) //to show the profile feature
  e.g. ->passwordReset() //to show the forgot password feature
  e.g. ->multiFactorAuthentication([AppAuthentication::make(),]) //to show the 2FA feature
  continue with the filament documentation for other features that you like to use
